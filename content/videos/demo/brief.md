# Brief : demo (exemple fictif)

Exemple fictif fourni avec le kit : produit « Acme », logiciel d'inscriptions pour clubs sportifs.
Les captures sont des **maquettes de remplacement** (badge PLACEHOLDER) générées par `npm run placeholders -- demo`.

## Produit

- Acme : inscriptions des membres et des bénévoles d'un club, en un seul endroit.

## Cible

- Responsables de clubs et d'associations, bénévoles, à court de temps.

## Message unique

> Acme automatise les inscriptions pour que vous retrouviez le terrain.

## Trois preuves

1. Connexion sans mot de passe (lien magique).
2. Autonomie : les membres choisissent leur poste, le système gère les quotas.
3. Contrôle : le délai d'inscription ferme les inscriptions tout seul ; export PDF.

## Appel à l'action

- Bouton : Essayer gratuitement ; URL : acme.example
- Affirmations confirmées : voir `content/brands/demo/brand.json > claims.allowed`.

## Contraintes

- Langues : fr, en. Formats : 16:9, 9:16. Pas de voix off.
